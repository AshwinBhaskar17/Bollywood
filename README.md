Bollywood Movie Data Analysis Using SQL
This project focuses on analyzing Bollywood movie data using SQL and MySQL. The dataset contains three tables: Movies, Actors, and Directors, which provide information about movie titles, release years, genres, actor and director details, movie counts, and normalized ratings.
The project explores Bollywood movie trends and industry performance using SQL queries, from basic data retrieval to intermediate and advanced analysis.

Key Concepts Covered
Basic Queries: SELECT, WHERE, ORDER BY, and COUNT.
Aggregate Functions: SUM, AVG, and COUNT.
Grouping and Filtering: GROUP BY and HAVING.
Joins: Combining movie and director information.
Subqueries: Comparing actor and director statistics with average values.
CASE Statements: Categorizing movies into Hit, Average, and Flop, and classifying actors and directors based on their activity.
Data Analysis: Identifying movie release trends, top actors, director rankings, and yearly movie production.

Key Findings
Analyzed the number of movies released in different years.
Identified the most active actors based on their movie counts.
Compared actor and director activity with average movie counts.
Examined normalized ratings to identify highly rated actors and directors.
Categorized movies according to their hit/flop ratings.
Explored yearly movie production levels and relationships between movies and directors.

Skills Gained
Through this project, I gained practical experience in SQL querying, data aggregation, joins, subqueries, conditional logic, and analyzing structured datasets to extract meaningful insights.
Tools Used: MySQL, SQL
Project Objective: To strenthen SQL skills through a real-world-style Bollywood movie data analysis project and uncover useful insights into movies, actors, directors, and production trends.
